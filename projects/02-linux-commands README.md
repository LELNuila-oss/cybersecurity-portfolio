# 02 - Linux Commands

## Objective
Practice essential Linux commands used in cybersecurity, system administration, and SOC analysis.

## Commands Practiced

| Command | Purpose |
|---|---|
| pwd | Show current directory |
| ls | List files and directories |
| cd | Change directory |
| cat | Read file content |
| grep | Search text inside files |
| find | Search for files |
| chmod | Change file permissions |
| ps | Show running processes |
| top | Monitor system processes |
| ip a | Show network interfaces |
| ss | Show network connections |
| journalctl | View system logs |

## Cybersecurity Relevance
Linux is widely used in servers, cloud systems, and cybersecurity tools. SOC analysts need basic Linux knowledge to review logs, inspect processes, and understand system behavior.

## What I Practiced
- Navigating the Linux terminal.
- Reading files.
- Searching text.
- Checking processes.
- Reviewing basic network information.
